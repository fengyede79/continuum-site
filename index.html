隐私政策

隐私与数据边界

续境的设计前提是本地优先：你的对话与记忆留在你的设备上。

草案 · 随服务上线更新

1. 我们保存什么

对话、长期记忆、索引与私人资料保存在你的本机资料目录中，由应用本地管理，不上传续境服务器。API 密钥保存在本地凭证库。

续境服务端只承载服务控制面元数据：账号、会话、权益与用量计数。服务端不建立聊天、记忆或模型请求内容的数据表。

2. 自带密钥（BYOK）

使用自带 API Key 时，对话内容由你的客户端直接发送给你选择的模型服务商（如 DeepSeek、通义千问），受该服务商自身的政策约束。续境不中转、不保存、不计量这些请求。

3. 托管模型（订阅）

订阅托管模型后，对话请求经续境网关转发给模型服务商以提供能力，并按用量计数。该转发将在用户协议中明确告知，你可随时停用。

4. 你的控制权

  • 纠正：记忆保留来源，你可以在应用内纠正与修订资料。
  • 删除：删除本地资料目录即清除全部对话与记忆；服务端账号数据可申请注销。
  • 迁移：资料目录可整体迁移到其他设备。

5. 反馈

反馈提交属于有意提交的数据，仅在获得单独同意后接收，保存期限与处理流程另行说明。
